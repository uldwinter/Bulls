# AIDossier

Operational AI governance workspace for SMEs preparing for the EU AI Act.

## Core features
- local-first AI system inventory;
- preliminary operational risk flags;
- Article 50 transparency notice templates;
- AI literacy and governance checklist;
- generated internal AI policy;
- PDF/print, CSV and JSON export;
- shareable system cards;
- no account, backend or paid API required.

## Important
AIDossier is a preparation and governance tool. It is not a legal opinion and does not replace the official EU AI Act Compliance Checker or professional advice.

## Run
Open `index.html` or use any static server.

## Build
```bash
npm run build
```
